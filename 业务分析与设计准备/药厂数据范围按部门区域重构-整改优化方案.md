### P5 服务商侧过滤语义不可照搬

`regionNamesInScope`（`useServingBizScope.ts:46-53`）：「范围为空 = 不限；**行未标区域 = 放行**；全国双向直通」。药厂侧是默认拒绝口径，必须反转为**「行解析不出区域 = 拒绝」**，否则 P4 无字段档会静默全放行。服务商侧该函数本身**不动**。

## 2. 目标模型与决策

三层模型（沿用已拍板）：**角色** = 能做什么操作 + 字段脱敏；**部门** = 管哪些区域；**成员授权** = 给谁、哪个角色、生效期。

| # | 决策 | 内容 |
| --- | --- | --- |
| D1 | 区域跟部门走（沿用） | 部门一对多挂省份；父子不自动继承、不向上汇总；「全国」与具体省份互斥；区域允许重叠（建部门 / 配置时提示共管）；未配置区域 = 普通成员默认拒绝；预置「企业管理员」（`role-pharma-admin`）固定全量，唯一例外 |
| **D2** | **区域锚点 = 品种授权链（本轮拍板）** | 省份取自品种授权、关联服务商与任务——「通过区域管辖服务商的任务成果」。**不给医院 / 拜访补省份字段。** 行区域解析顺序：① 行自带 `regions`/`region` → ② 行有 `taskId` → 所属 `task.regions` → ③ 行有 `(provider, variety)` → `relationshipsOfPharma` 解析 providerTenantId 后取 `authorizedVarietyLinesOfPharma(providerTenantId, pharmaTenantId)`（`cooperationModel.ts:1120-1134`）中该品种的授权区域（品种行 `lineRegions` 缺省回退关系级区域，见 GrantedVarietyLine :1113-1117）→ ④ 都解析不出 → 不可见。品种名匹配复用 `varietyInScope` 的归一化逻辑 |
| **D3** | **多省任务任务级匹配（本轮拍板）** | `task.regions ∩ 我的区域 ≠ ∅` 则**整单可见**（含全部明细 / 金额 / 导出）。替代早期「不能暴露整单辖区外明细」约束，记为有意决策；hook 仍按区域暴露单行谓词（`matchesRegion`），日后合规要求明细裁剪可低成本叠加 |
| D4 | 区域规范词 | 统一存 `PROVINCES` 短名 + 「全国」；写入侧经 `normalizeRegionName` 归一后校验；`orgRegions.ts` 种子（全名）迁移为短名；`TaskExecution.tsx:2145-2168` 兜底文案同步改短名 |
| D5 | 「全国」匹配语义 | 部门含「全国」= ALL；行区域含「全国」→ 对任何有 ≥1 区域的成员可见 |
| D6 | 组织数据唯一真源 | tenantRegistry 持久 state 扩展为组织真源（部门 + `managedRegions` + memberships），PermissionContext 从 `allOrgs()` 水合并经 registry commit 回写；`orgRegions.ts` 退役，区域并入 `PermOrg.managedRegions` |
| D7 | 验收链校验 | `reviewBatch` 增加审核人部门比对：审核人 `membership.orgUnitId → org.name` == `departments[level-1]` 方可通过 / 驳回；企业管理员可越过；日志改记审核人**实际**部门；`AcceptanceChainConfig` 结构不动 |
| D8 | 「查看授权」落点 | 成员行新增「查看授权」→ 跳用户管理并预选该用户、自动打开详情弹窗（复用 NavFocus 预选模式，同 PharmaCooperation→BusinessAuthorization）；详情弹窗内药厂租户隐藏 `scopeLabel`、改显「部门管理区域」 |

### 阶段 2 · 药厂侧运行时区域过滤（P4 / P5，3–4 天）

**新 hook：`src/hooks/usePharmaRegionScope.ts`**（与 `useServingBizScope` 同构、语义反转）

```ts
interface PharmaRegionScopeView {
  mode: 'ALL' | 'NONE' | 'REGIONS'
  regions: string[]                    // 短名；ALL 时为 ['全国']
  denied: boolean                      // mode === 'NONE'，业务页渲染空态
  /** 严格口径：按 D2 顺序解析行区域；解析不出 → false（默认拒绝） */
  matchesRow(row: { regions?; region?; taskId?; provider?; variety? }): boolean
  /** 行区域解析器（导出供分组 / 汇总 / 导出复用） */
  regionsOfRow(row): string[] | null
  /** 单区域谓词（D3 预留明细裁剪扩展点） */
  matchesRegion(name: string): boolean
}
```
