# 业务明细导出 — 需求描述

> 对应原型页面：`业务分析与设计准备/src/pages/BizDetailExport.tsx`（页面标识 `biz-detail-export`）
> 权限模块：统计管理 / 业务明细导出，动作 `view / create / export`
> 文档日期：2026-11-10（基于原型现状整理，标注了原型演示行为与正式环境的差异）

---

## 1. 背景与目标

在药厂（业务归属方/持有人）与服务商（服务提供方）的推广合作模式下，双方按「对账单」周期性结算业务费用。财务对账、合规自查与审计归档都需要一份**以对账单为核心、汇总业务明细与凭证证据**的正式报告。

本模块提供从 **筛选统计口径 → 勾选业务类型 → 选择报告模板 → A4 单页预览 → 导出 PDF 归档** 的一站式报告生成能力：

- **对账核对**：将「结算单申报金额（服务方申报）」与「凭证生成金额（实收票据）」并列呈现，直观暴露差额；
- **证据链归档**：按业务类型汇总核验单据（打卡记录、签到表、会议纪要、回执等），形成可存档的 A4 单页；
- **审计留痕**：报告编号唯一、生成时间与流转历史可追溯。

## 2. 用户与入口

| 端 | 入口 | 说明 |
| --- | --- | --- |
| 药厂工作区 | 业务管理 → 业务明细导出 | 数据限定为本厂业务范围，并叠加部门管理区域过滤 |
| 服务商工作区 | 业务管理 → 业务明细导出 | 数据限定为当前服务药厂 + 已授权品种 |

- 权限：`biz-detail-export`（view 查看 / create 创建 / export 导出），按钮与操作按动作裁剪。
- 套餐：该模块为租户套餐可选内容，未包含的套餐不展示入口。
- 页面介绍文案随身份域变化：服务商侧提示「已按当前会话服务药厂与已授权品种过滤」；药厂侧提示「已按本厂业务范围过滤」。

## 3. 功能需求

### 3.1 报告台账（列表视图）

以卡片表格展示当前会话范围内的历史导出报告，默认按创建时间倒序，每页 10 条。

**列表字段**：序号、报告名称（草稿带「草稿」标签）、对账单编号、服务提供方、品种、业务记录数（笔）、创建时间、操作。

**筛选条件**（选项随会话范围联动刷新）：

- 对账单编号（文本模糊匹配）
- 服务提供方（下拉，取自会话内已有报告）
- 品种（下拉，取自会话内已有报告）
- 创建时间 起 / 止（日期区间）

**操作**：

| 行状态 | 操作 |
| --- | --- |
| 已归档 | 查看（打开详情抽屉）｜ 下载 PDF ｜ 更多（复制报告编号） |
| 草稿 | 继续编辑（回到向导第二步）｜ 删除（二次确认，仅删除草稿记录，不影响已归档报告与结算数据） |

**页头动作**：

- 「导出报告」：导出当前筛选下的报告清单；
- 「创建业务明细导出报告」：进入三步向导；
- 空态引导：无匹配数据时提供「调整筛选条件」说明与创建入口。

### 3.2 创建向导（三步）

步骤条支持点击切换，三步为：**选择业务类型 → 选择报告模板 → 单页预览与导出**。

#### 第一步：选择业务类型

**（1）导出报告生成条件设置**

| 条件 | 必填 | 形态 |
| --- | --- | --- |
| 服务提供方 | ✔ | 下拉；服务商侧固定为本企业，药厂侧为本厂有合作的服务商 |
| 品种 | ✔ | 下拉；随所选服务商联动，且限定在会话授权范围内 |
| 工作组 | | 下拉（全部工作组 / 具体工作组） |
| 服务专员 | | 下拉（含专职/兼职） |
| 绩效状态 | | 下拉（已考核 / 全部 / 待考核） |
| 导出内容 | | 下拉（导出全部内容 / 仅导出汇总 / 仅导出凭证明细清单） |
| 工作量周期 | | 文本（如 `2026-08-10 - 2026-09-10`） |
| 记住选项 | | 复选，下次进入向导回填 |

- 「重新统计数据」：按当前条件对**已勾选**类型重新统计，徽章进入「统计中」后错峰出数；
- 参数实时核对提示：无统计时显示「待选择业务类型后统计」，统计中显示进行中数量，完成后显示「参数实时核对完成」。

**（2）业务类型卡片（六类）**

| 业务类型 | 数据来源（统计口径） | 数量单位 |
| --- | --- | --- |
| 学术拜访服务 | 拜访记录·学术拜访 | 次 |
| 日常拜访服务 | 拜访记录·日常拜访 + 跟踪巡访服务 | 次 |
| 科室会议服务 | 任务服务项目·科室会议 | 场 |
| 学术推广服务 | 任务服务项目·学术推广 | 次 |
| 调研问访服务 | 拜访记录·信息收集和调研 | 份 |
| 研究报告服务 | 任务服务项目·分析报告服务 | 份 |

交互规则：

- 默认全部不选中；**勾选后**系统按当前筛选条件实时统计该类型数据量，徽章状态机为「未统计 → 统计中（转圈）→ 出数（数字滚动）」，支持全选/反选；
- 取消勾选后数字清除、回到「未统计」；
- 切换服务商或品种时自动触发重新统计；
- 数据量仅为参考提示，**最终以导出报告内容为准**；
- 校验：未勾选任何类型时「下一步」禁用，并提示「请至少勾选一种业务类型后继续」。

#### 第二步：选择报告模板

**（1）模板卡片（三款，均为 A4 单页）**

| 模板 | 内容模块构成 | 适用场景 |
| --- | --- | --- |
| 标准证据链（默认推荐） | 基础信息 + 业务摘要 + 证据文件清单 | 日常业务对账与归档核验 |
| 对账汇总 | 金额摘要 + 业务明细 + 结算状态 | 财务专员与审计高管快速核对金额与结算状态 |
| 时间线审计 | 提交记录 + 审核记录 + 结算归档 | 查看推广全生命周期的审批、结算与凭证流转 |

每款模板提供 A4 版式线框缩略图与适用说明。

**（2）报告排版与要素控制**

- 报告标题名称（文本，可编辑，默认「YYYY 年 MM 月业务明细导出报告」）；
- 页面方向：纵向（Portrait）/ 横向（Landscape）；
- 是否显示独立金额比对（结算/凭证双金额）；
- 是否显示证据文件摘要（会议/签到清单汇总）。

**（3）本步动作**：上一步修改业务类型 ｜ **暂存草稿** ｜ 预览单页报告。

#### 第三步：单页预览与导出

**（1）A4 真实比例预览**（210mm×297mm / 297mm×210mm），版面自上而下：

1. 抬头：系统名 + 报告标题 + 报告编号；
2. 对账单信息：对账单编号、服务提供方、推广品种、结算周期（取当前会话内最近一张已确认且未作废的结算单）；
3. 金额汇总（受「显示独立金额比对」开关控制）：结算单申报金额（含业务笔数）与凭证生成金额，并显示差额；
4. 业务类型统计表：服务类型、发生频次、核验单据说明、结算金额，含合计行；
5. 证据文件摘要（受开关控制）；
6. 页脚声明与「财务对账审核章」、生成时间。

**（2）导出设置核验（右侧栏）**：报告文件名（默认为标题去空格）、页面规格、数据统计核对（已选类型数 / 申报金额 / 凭证金额 / 核对状态）、显示要素开关回显。

**（3）导出动作**：点击「导出单页 PDF 报告」→ loading（正在生成单页 PDF 报告…）→ 成功弹窗，弹窗内提供：返回列表 ｜ 查看报告（打开详情抽屉）｜ 下载 PDF。

### 3.3 报告详情抽屉

从列表「查看」或导出成功弹窗进入，内容包括：

- **报告核验状态**：草稿未归档 / 审核合格已归档；报告编号（可一键复制）；
- **对账金额明细清单**：结算单金额（服务方申报）与凭证生成金额（实收票据）并列，显示业务笔数与差额；
- **业务报告流转历史**（时间线）：生成单页报告 → 风控部门复核 → 财务结算发票初核，逐节点展示时间、操作人与结论；
- 底部动作：关闭 ｜ 打开单页预览 ｜ 直接下载 PDF。

### 3.4 草稿管理

- 暂存草稿：将当前向导配置写入报告台账（状态=草稿），分配报告编号与关联对账单编号，可继续编辑或删除；
- 删除草稿需二次确认，明确提示「尚未归档，删除后不可恢复」，且仅删除草稿本身。

## 4. 业务规则

1. **双金额口径**：「结算单金额」= 服务方申报口径；「凭证生成金额」= 实收票据口径。两金额支持分别核对与统计，差额在预览、详情中始终可见。
2. **对账单锚定**：报告以对账单为组织单元（页面文案「按对账单与服务方生成」）；预览用的对账单取会话范围内最近一张已确认且未作废的结算单。
3. **编号规则**：报告编号 `BG-yyyyMM-xxxx`，与对账单编号 `DZ-yyyyMM-xxxx` 建立可视关联。
4. **状态机**：`草稿 → 已归档`。正式环境中导出成功即完成系统归档；归档报告只读，可下载与查看流转历史。
5. **统计口径透明**：每类业务类型在卡片上注明数据来源与包含的单据类型，避免统计歧义。

## 5. 权限与数据范围（强约束）

1. **会话统一口径（P0-E）**：
   - 服务商会话 = 当前服务商 × 当前服务药厂 × 已授权品种；
   - 药厂会话 = 本厂数据；
   - 范围失效默认拒绝：无业务范围时整页展示拒绝空态。
2. **部门管理区域过滤（D2/D3）**：药厂会话在业务范围之上按用户管理的区域叠加过滤；任务行自带区域，拜访/台账行经 `taskId → 任务` 或品种授权链解析归属区域。
3. **同源过滤**：列表、详情、草稿、统计、筛选下拉、导出结果全部使用同一份会话过滤结果，不允许出现「列表看不到、导出能导出」的旁路。
4. **动作权限**：`view` 控制入口与列表，`create` 控制创建向导与草稿，`export` 控制下载 PDF 与清单导出。

## 6. 非功能需求

1. **导出文件**：正式环境生成 A4 单页 PDF，文件名默认为报告标题；支持打印与内部财务审计存档。
2. **统计反馈**：数据量统计为异步查询，界面以「统计中」徽章给出来焦反馈，避免大数据量下的界面假死感；动效遵循 `prefers-reduced-motion`。
3. **审计追溯**：报告生成、复核、归档动作写入流转历史；操作人、时间可追溯。
4. **预览一致性**：预览版面与导出 PDF 版面保持一致（所见即所得）。

## 7. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 会话无业务范围 / 无区域范围 | 整页拒绝空态，不展示列表与向导 |
| 未勾选业务类型 | 「下一步」禁用 + 文案提示；「重新统计」给出未选择类型的提醒 |
| 筛选无匹配报告 | 列表空态 + 创建入口引导 |
| 无可关联结算单 | 预览中对账单信息字段显示占位「—」 |
| 切换服务商/品种 | 下拉选项联动刷新并自动重算统计 |
| 删除草稿 | 二次确认，明确影响范围仅限草稿本身 |

## 8. 原型演示行为（正式环境需替换）

以下为原型为演示效果所做的处理，实现时按真实数据与流程替换：

1. 导出动作不生成真实文件，以提示说明「导出后应下载《标题》.pdf」；
2. 报告台账种子数据（28 条）由演示「服务商 × 药厂 × 品种」矩阵派生；
3. 业务类型卡片的「申报金额」按凭证金额上浮约 2% 生成，仅用于演示双金额口径；
4. 数据量统计在前端对会话内演示明细即时计算，正式环境应为服务端按筛选条件的真实聚合查询；
5. 详情抽屉的流转历史为固定演示节点。

## 9. 待确认问题（开放点）

1. 归档前是否需要「风控复核 → 财务初核」的正式审批流，还是导出即归档？流转历史节点需与实际流程对齐。
2. 「记住选项」的作用域：用户级还是租户级？记住哪些字段（是否含服务商/品种）？
3. 「导出内容」三选项（全部 / 仅汇总 / 仅凭证明细清单）对 PDF 版面的具体裁剪规则。
4. 工作组、服务专员、绩效状态三类筛选在正式环境的数据来源与统计口径（当前原型为静态选项）。
5. 列表页头「导出报告」（清单导出）的格式与字段范围（当前原型仅 toast 演示）。
6. 一份报告是否允许跨多张对账单（当前按单张对账单锚定），跨周期报告如何组织。
