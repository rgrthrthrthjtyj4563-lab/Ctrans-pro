# 业务明细导出 · Figma 优化提示词

请基于我提供的「新建报告」抽屉截图修改现有原型。沿用列表右侧抽屉、白底、深绿色主按钮、浅绿色摘要卡片和固定底部操作栏。保留约 600px 宽的桌面抽屉。整个新建流程在这一个抽屉完成，取消区块前的步骤编号。抽屉主体从上到下为「导出范围」「本次导出摘要」「导出类型」，底部只有「取消」「生成报告」。

## 导出范围

顶部放「按对账单」「按组合条件」两个互斥选项，默认「按对账单」。切换时原位替换范围表单。每种方式在本次打开抽屉期间保留各自输入，摘要仅显示当前方式、当前条件对应的结果。

### 按对账单

保留截图的可搜索对账单选择器。仅展示当前身份可访问、已确认且未作废的对账单。选中后显示服务提供方、品种和结算周期，并直接加载该单的摘要。服务提供方、品种和结算周期是只读信息。导出范围为该单实际纳入结算且有权访问的业务，含部分结算时使用本单纳入的工作量。

### 按组合条件

模式下方文案「按工作量归属周期导出业务明细」。在同一块表单中紧凑排列五个字段。工作量周期占整行，四个维度两列排列。

| 字段 | 控件和默认值 |
| --- | --- |
| 工作量周期 | 必填。起止月份选择器，支持单月或跨月，含起止月份。帮助文案「按业务的工作量归属月份筛选」 |
| 服务提供方 | 药厂端可搜索单选，默认「全部授权服务提供方」。服务商端固定为本企业 |
| 工作组 | 可搜索多选，默认「全部工作组」。如范围内存在直派专员记录，提供「无工作组」选项 |
| 品种 | 可搜索多选，默认「全部品种」 |
| 服务专员 | 可搜索多选，默认「全部服务专员」。同名时显示所属服务提供方或可辨识的账号信息 |

字段之间同时满足，同一字段选择多个值时匹配任一。周期是查询边界，其余维度可任意组合。查询范围受当前工作区及角色授权限定。用历史业务记录上的归属匹配工作组和专员。切换服务提供方或工作组时刷新相关选项，清除失效选择并提示具体被清除的字段。历史记录的归属缺失时，可以纳入未限定该维度的查询。指定了该维度时，仅纳入归属明确且匹配的记录。

条件区底部右侧放次按钮「应用条件」。选择、取消、输入搜索关键字时只更新编辑条件或下拉选项。用户点「应用条件」后统一查询摘要。首次进入显示「选择工作量周期后，应用条件查看结果」。修改已应用的条件后，将旧摘要标记为「上次结果」，提示「条件已修改，请重新应用」，底部暂不可生成。

组合条件范围可包含跨对账单和未结算的合规可导出业务。摘要、文件和列表统一标记「组合条件」，显示实际条件与工作量周期。对账单编号只在明细行已有真实关联且可查看时展示。组合条件不展示整单结算总额。

## 本次导出摘要

复用截图的浅绿摘要卡。查询成功时展示「已选 4 类 · 32 条业务记录」及本次范围。在对账单方式下，范围展示对账单号；在组合条件方式下，展示已应用的服务提供方、工作组、品种、服务专员及周期。过长时可展开完整范围。

「调整业务类型」默认折叠。展开后显示学术拜访、日常拜访、科室会议、学术推广、调研问访、研究报告六类及各自数量。默认勾选所有有记录的类型；无记录的类型显示 0 且禁用。更改类型直接更新已选类型数和记录数，复用当前摘要。切换对账单或首次应用一组新条件时，按新结果默认全选有数据的类型，并清楚展示选择状态。

分别设计「查询中」「未找到符合条件的业务」「读取失败，可重试」三种局部状态。授权只有部分时标明「仅含当前权限内记录」。摘要未就绪、条件未应用、已选记录为零时，禁用生成并就地说明原因。

## 导出类型（必选，支持多选）

在摘要下方单独放一个紧凑的复选框组。组标题「导出类型」，标题右侧放全选复选框「全选格式」，有未选、部分选和全选状态。

| 选项 | 辅助文案 |
| --- | --- |
| 导出明细 PDF 版（.pdf） | 固定 A4 版式，含范围、汇总、业务明细和证据文件清单，自动分页，便于阅读、打印和存档 |
| 导出明细 Excel 版（.xlsx） | 含导出说明、业务明细和证据文件清单工作表，便于筛选、核对和二次统计 |

默认勾选 PDF 版。用户可仅选 Excel，也可点「全选格式」同时选择 PDF 和 Excel。再次点已全选的复选框可取消全部。至少选择一种格式才能生成。全选格式只作用于这两种文件格式，与上方业务类型选择分开。

两种文件使用同一批记录和同一组已应用条件，导出所有符合条件且已选类型的记录。证据文件清单只列文件信息和关联业务。组合条件文件的明细应支持查看业务编号、类型、服务提供方、工作组、品种、服务专员、工作量归属月份、工作量及单位，并记录本次筛选条件。报表名称按来源和周期自动生成。

## 提交生成和列表下载

点击「生成报告」立即提交后台任务。提交成功关闭抽屉，列表新增一条任务并提示「已提交，生成后可在列表下载」。勾选两种格式时只创建一条任务，分别生成两个文件，列表显示各自状态。生成前不设置模板页、预览页和确认弹窗。

- 两种文件都已生成时提供「下载 PDF」「下载 Excel」。
- 一个已生成、另一个仍在生成时，已完成的文件可先下载。另一个标记「生成中」。
- 一个成功、另一个失败时，任务显示「部分完成」。成功文件可下载，失败格式可单独重试。
- 下载失败时提示重试下载。提交前发现范围数据已变化时，在当前抽屉刷新摘要并提示用户确认后再次点击生成。切换条件或模式后，迟到的查询结果不可覆盖当前摘要。

报告列表加「导出范围」或在标题下区分「按对账单」「按组合条件」，用格式标签显示 PDF、Excel。对账单方式可显示编号，组合条件方式展示周期及关键筛选标签，支持展开查看完整条件。
