# 医药代表备案管理功能优化说明（仅药厂角色）

## 结论

药厂侧不需要把“备案”做成复杂的多级审批。药厂合规人员确认代表资格和推广范围后，由**药厂备案专员**在国家备案平台提交，并在本系统回填备案号即可。

现有页面最大的问题是：新建代表时要求先填“备案号、备案有效、风险核验通过”。备案号确实在药厂提交国家平台后才产生，但页面必须始终展示该字段：新建时显示“待取得”，登记国家平台结果后显示正式备案号。流程应调整为“先建档确认资料，再提交备案，再回填备案结果”。

## 一、药厂角色下保留的字段

| 页面区域 | 字段 | 是否必填 | 调整说明 |
|---|---|---:|---|
| 基本信息 | 姓名、证件类型、证件号、手机号、邮箱 | 是 | 保留；证件号继续脱敏展示 |
| 基本信息 | 性别、照片 | 是 | 新增；国家备案需要 |
| 资格信息 | 学历、专业、学历证明 | 是 | 保留；学历须大专及以上，专业为医学、药学或相关专业 |
| 资格信息 | 培训计划、培训完成日期、考核成绩、培训证书 | 是 | 保留；考核通过才可提交备案 |
| 合规承诺 | 承诺书版本、签署日期、承诺附件 | 是 | 保留；必须为当前有效模板 |
| 聘用/授权 | 雇佣类型、劳动合同/授权书编号、开始日期、结束日期、附件 | 是 | “雇佣起止日期”改为明确的合同或授权期限 |
| 推广范围 | 药品类别/产品、治疗领域、推广区域 | 是 | 从现有“授权”页前移到备案前；国家备案前必须确认范围 |
| 国家备案 | 国家备案号、提交日期、提交人、备案回执 | 提交成功后必填 | 新增/调整；仅药厂备案专员可填写 |
| 企业内控 | 风险筛查结果、筛查日期、证据 | 按公司规则 | 保留，但标注为“企业内控”，不再叫“备案核验” |

## 二、药厂侧应删除或替换的字段

| 现有字段/动作 | 调整为 | 原因 |
|---|---|---|
| 新建表单中的“备案号” | 保留为只读字段；新建时显示“待取得”，提交成功后回填正式编号 | 备案号不是申请前置条件，但必须始终可见 |
| 新建表单中的“备案状态：有效” | 移除 | 药厂提交后取得备案号，不应让申请人预先选择“有效” |
| “有效授权” | 改为系统计算标签 | 以已通过、未替代、覆盖当前日期的授权范围及授权截止日计算；不得人工选择 |
| `filingVerifiedAt`（备案核验日期） | `filingSubmittedAt`（国家平台提交日期） | 记录真实对外操作 |
| `nextVerifyDate`（下次核验日期） | 删除 | 法规没有固定 90 天复核要求 |
| “人工核验 / 接口核验 / 批量复核” | “登记国家平台提交结果” | 当前未接国家平台接口，不应模拟监管审核 |
| “批量核验并判定有效” | 删除 | 不应批量把代表判定为备案有效 |
| `filingStatus=有效/无结果/失效/异常待人工确认` | `待提交/已备案/提交失败/变更待提交/删除待提交/已删除` | 改为真实备案生命周期 |

## 三、药厂角色下的最小操作流程

```text
药厂业务人员建档
  → 药厂合规确认学历、培训、承诺及内控筛查
  → 药厂业务负责人确认合同/授权及推广范围
  → 药厂备案专员在国家平台提交
  → 回填备案号、提交日期、回执
  → 状态为“已备案”
```

### 状态和按钮

| 当前状态 | 药厂可见按钮 | 进入条件 |
|---|---|---|
| 草稿 | 编辑、提交合规确认 | 基本资料已保存 |
| 待合规确认 | 通过、要求补件、不通过 | 学历、培训、承诺资料齐全 |
| 补件中 | 编辑、重新提交 | 补齐合规要求资料 |
| 待备案提交 | 登记国家平台提交结果 | 合规通过，且合同/授权和推广范围已确认 |
| 已备案 | 发起备案变更、发起删除 | 已有备案号和回执 |
| 变更待提交 | 登记变更结果 | 姓名、证件、学历、合同期限、产品/领域/区域等备案信息改变 |
| 删除待提交 | 登记删除结果 | 离岗、停止授权或严重违规 |

“已备案”不等于可开展全部活动；活动仍须校验合同/授权未到期，以及产品、治疗领域和区域未超范围。

## 四、最小权限划分

| 药厂角色 | 可操作字段/动作 |
|---|---|
| 业务人员 | 基本资料、合同/授权资料、推广范围；提交合规确认 |
| 合规人员 | 学历、培训、承诺、企业内控筛查；通过、补件、不通过 |
| 备案专员 | 国家备案号、提交日期、回执、变更/删除结果 |

合规人员不能审批自己发起的记录。备案专员可以与合规人员是同一岗位，但系统仍应分别记录“合规确认人”和“备案提交人”。

## 五、验收口径

1. 新建代表时备案号字段始终展示“待取得”，不要求人工填写或选择“备案有效”。
2. 合规通过且已确认合同/授权、产品、治疗领域、区域后，才出现“登记国家平台提交结果”。
3. 未填备案号和回执时，不能标记为“已备案”。
4. 修改备案字段后，自动变为“变更待提交”；停止授权或离岗后，自动变为“删除待提交”。
5. 列表展示“备案状态 + 备案号 + 有效授权”；其中“有效授权”仅显示系统计算结果，不提供人工编辑。

法规依据：[《医药代表管理办法》第 13—17 条](https://mpa.yn.gov.cn/zfxxgk/zcwj/qtwj/gjwj/202605/t20260519_3025962.html)。
