## 2. 现状基线（原型已实现——"现状/第一期已落地"章节照此写）

### 2.1 第 1 段：企业/工作空间验证
- 输入 8 位企业编码（自动大写、仅字母数字）；解析成功显示企业卡片（名称 + 编码 + 「切换企业」返回按钮）。
- 系统管理后台编码（M8QT3ZRN）解析为 **realm=PLATFORM**（软件服务方专属域，不伪装成企业租户），文案显示「工作空间验证」「已识别：系统管理后台（软件服务方）」，第 2 段手机号标签为「软件服务方工作人员手机号」；企业码解析为 realm=TENANT。
- 失败统一「企业编码不存在或已停用，请核对后重试」（不存在/停用/暂停/终止不区分，防探测），错误定位到编码输入框。
- **套餐到期在第 1 步拦截**：提示「该企业的系统开通已于 {日期} 到期，登录已停止；请联系软件服务方续期」（原因码 TENANT_EXPIRED）。
- 企业码规则：8 位大写字母数字、排除易混字符 0/O/1/I、无业务语义、一个企业一个主码、终止后退役保留不得复用。
- **记住企业**（本设备，最多 5 条）：快捷条目仅回填编码，每次点击都重新解析（不信任缓存）；解析失败静默删除该条并提示重输；删除条目需确认弹框。
- 切换/重新解析时作废全部在途请求并清空第 2 段状态（短信回显、账号、密码、错误）。

### 2.2 第 2 段：短信登录
- 输入本企业手机号（11 位校验）→「发送验证码」（60s 倒计时重发）→ 6 位分格输入（支持整段粘贴自动分发、退格回退到前一格）。
- 票据规则：TTL 5 分钟；错 1 次提示「验证码不正确，还可尝试 N 次」，**连错 3 次作废**（提示重新获取，前端同步清空输入与回显）；重发即覆盖旧码（旧码失效）；票据键 = `enterpriseId:phone`。
- 防枚举：非本工作空间成员请求验证码 → 返回随机假码且永不校验通过；请求阶段一律统一成功态（不暴露成员身份）。
- 演示口径：成员验证码固定 123456 且页面明文回显「模拟短信 · 5 分钟内有效」。

### 2.3 第 2 段：密码登录
- 输入登录账号或手机号（账号在企业内唯一，3–20 位小写字母/数字，可含 `-` `_`）+ 密码（明暗文切换）。
- 失败分支（顺序）：账号不存在/密码错误（统一文案，含剩余次数提示）→ 账号锁定 → 租户不可登录 → 非本企业成员 → 成员冻结 → 成员移除 → 待激活（放行+激活）→ 授权判定。
- 勾选「记住默认登录」时密码登录与短信登录同样支持。

### 2.4 账号锁定（P0，新实现）
- 按 userId 计密码连续错误：**第 3 次起**提示「还可尝试 N 次」；**第 5 次锁定 15 分钟**；锁定期内**密码正确也拒绝**，提示「密码连续输错次数过多，账号已锁定，请 N 分钟后重试，或改用短信验证码登录 / 找回密码」。
- 计数清零：登录成功 / 管理员解锁 / 找回密码重置。
- 管理端：用户管理列表行内 + 用户详情「解锁登录」（仅锁定中账号显示），确认弹框，写审计 LOGIN_UNLOCKED；锁定触发写 PASSWORD_LOCK_TRIGGERED。
- 守卫记录按设备持久（刷新不逃逸）；生产为服务端计数（文档定义）。

### 2.5 修改密码（P0，新实现）
- 入口：顶栏用户菜单 →「账号与安全」弹窗（三个字段：当前密码 / 新密码 / 确认新密码）。
- 规则：当前密码错误单独提示（不与其他错误合并）；新密码须符合 8–20 位含字母数字；新密码不得与当前相同；两次输入一致。
- 成功：审计 PASSWORD_CHANGED，本设备保持登录；失败（旧密码错）：审计 PASSWORD_OLD_WRONG。
- 生产增强（文档定义）：改密后吊销其他已登录会话、要求重新登录。

### 2.6 找回密码（P0，新实现）
- 入口：登录页密码子方式「忘记密码？」（密码标签行右侧）→ 两步弹窗：
  - 第 1 步（定位）：输入本企业登录账号或手机号 → 在企业命名空间内定位 → 停用账号拦截（「该账号已停用，无法自助找回密码，请联系企业管理员」）→ 向账号绑定手机号发送短信验证码（复用票据与防枚举机制）；
  - 第 2 步（重置）：6 位验证码 + 新密码 ×2 → 校验码与密码规则 → 重置成功：**同步清除登录锁定与失败计数**、审计 PASSWORD_RESET、展示成功态并「返回登录」（自动回填登录账号、聚焦密码框）。
- 弹窗顶部展示当前企业名与编码；切换企业时弹窗关闭。

### 2.7 记住默认登录（30 天）
- 开关默认不勾选（短信/密码两子方式共用）；**勾选且验证成功**才保存：记录 = userId + 工作空间（类型/id/名称）+ 服务商最近服务药厂（可空）+ deviceId + 保存/过期时间；**不含验证码、密码或任何凭证本体**。
- 应用启动自动尝试恢复：免验证码直进默认工作空间；恢复链实时重校验（任一失败即清记录 + 撤销审计 + 登录页一次性提示）：未过期 → 账号可用 → 租户可登录 → 本企业成员身份有效 → 存在可用角色；服务商身份的最近服务药厂仍可进入才沿用，否则回退选药厂门页。
- 登出 = 立即撤销本设备默认登录记录（审计）。
- 服务商切换服务药厂后同步更新记录中的最近药厂。

### 2.8 登录成功后的身份判定链（登录域收口）
- **多角色自动合并**：同企业全部生效角色并集进同一会话——功能权限按权限点取并集、字段脱敏从严（visible < mask < hidden 取最严）、数据范围为全部授权记录并集；平台域恒单角色。
- **状态拦截链**（验证成功后按序披露，均有标准文案与原因码）：
  1. 租户暂停/终止 → 统一「企业编码不存在或已停用」（在途票据同时失效）；
  2. 自然人账号停用 →「该账号已停用，请联系管理员」；
  3. 企业级成员冻结 →「该账号在本企业已被冻结，请联系企业管理员」（仅本企业）；
  4. 成员已移除 →「你在本企业的成员身份已被移除，如需恢复请联系企业管理员」（仅本企业，自然人其他企业不受影响）；
  5. 待激活 → **放行并自动激活**：一次性提示「账号已激活，欢迎加入」+ 首登激活庆祝弹框（无按钮 5 秒自灭）；运行时建租的首位管理员激活联动租户 待激活→正常；
  6. 授权判定：无可用角色 / 授权过期 / 复核中 / 已回收 → 各自标准文案；
  7. 服务商业务身份（服务专员/工作组组长）全部无服务药厂范围 →「尚未获分配可处理的业务药厂范围…」拦截。
- **服务商选药厂门页**（登录第 3 步，步骤条「企业验证 → 短信验证 → 选择服务药厂」）：仅服务商业务身份且名下有待选药厂时出现；**单药厂直达**（不进门页、不弹庆祝）；卡片四类状态——阻断（合作暂停/终止、业务授权撤销、无范围：不可进入但展示原因）/ 警告（备案类：可进入、仅拦学术拜访）/ 服务中；多记录时禁用卡点击展示原因；确认进入弹框（展示所属企业、身份、数据范围）；门页停留期间合作变化实时刷新；全部不可用时空态列原因清单。
- **多企业身份**：同一手机号可在多家企业分别建档，各自独立状态；跨企业访问 = 退出后用另一家企业码重新登录。
