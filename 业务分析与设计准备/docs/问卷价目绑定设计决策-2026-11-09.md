# 问卷价目绑定设计决策｜2026-11-09

本文记录问卷与价格如何绑定的一次设计讨论结论。业务背景来自《新系统问卷设计参考-业务上下文》（美罗场景，2026-11-09 整理），讨论发生在药合作原型「价目表配置」页的问卷调查大类上下文中。

## 已拍板的决策

| 决策点 | 结论 |
| --- | --- |
| 绑定模式 | **价目侧绑定**：价目行维护「适用问卷范围」（多选问卷库）；问卷库不存价格，仅只读回显当前适用价目 |
| 档位维度 | 问卷调查价目类别的档位 = **填写对象**（医生 / 患者 / 商业公司） |
| 价格锁定时点 | 任务下发时价格与题目版本一起锁定快照；之后改价、换版本不影响已下发任务 |
| 原型改动 | 先补「编辑类别」弹窗的档位改名能力（已完成，见下） |

## 为什么选价目侧绑定

1. **与已确认结论一致**：此前讨论已明确「问卷主题和报价分开；同价的多份问卷共用一条价目」。价目侧绑定天然支持一条价目挂 N 份问卷。
2. **品种隔离的硬约束**：现有价目架构价格按品种隔离、公私两套、草稿-发布。而问卷的品种可空（=全品种）。若在问卷侧存价格，等于要在问卷里重建「品种×价格」矩阵，两头维护。
3. **职责分离**：定价是商务/结算域动作（价目模块），建问卷是内容域动作（问卷库）。问卷侧绑定会迫使建问卷的人定价。
4. **对齐版本心智**：题目版本在任务下发时锁定，价格快照同节奏锁定，业务规则同构。

对发包标准价机制的例外：现有「每业务大类一个发包标准价」在问卷场景不成立（每份问卷一个价），问卷调查大类改为按问卷取价、不参与单标准价选择。

## 与价目表方案的阶段关系

「基础价目表关联适用问卷 → 拆包弹框带出各问卷单价 → 分别填计划量 → 汇总金额」目前仍是独立演示原型（`问卷专属二维码原型/问卷价目表与拆包.html`），未成为主流程正式计价规则。本决策确认其方向，落地节奏另定。

## 落地记录（第四批：采纳外部评审，模型升级 v2）

外部 AI 评审意见（全文要点）：倾向 C 但重新定义——**价目侧负责定价和适用规则，问卷侧提供配置入口，任务下发时锁定计价结果**；不建议把「价目上的问卷清单」当底层模型；三个问题（数据怎么存/谁有权配置/从哪里操作）应分别设计；先说清「绑定什么」——问卷引用的应是**计价方案**（由价目类别承载，按品种×公私×填写对象解析出唯一价格），而非某条具体价格行。

**采纳结论（现行模型 v2，替代第三批的清单式绑定）**：

1. **计价方案 = 问卷调查大类的价目类别**（档位=填写对象，价格按品种/公私在价目页维护），不新增对象。
2. **绑定 = 默认规则 + 例外绑定**（结构性消歧，例外 > 默认，无跨方案优先级比对）：
   - 默认方案粒度 = 业务大类（问卷调查一个默认），品种差异由方案内分品种价格行表达；
   - 例外 = 问卷编码 → 专属方案，逐份设置。
3. **关系独立维护、归价目配置权限域**：问卷侧「计价」入口需 `price-config edit`，否则只读；新建问卷**不强制**选价目（商务规则不是内容必填字段）。
4. 实现：`questionnaireStore.ts` v2（`link: { defaults, exceptions }` + 方案登记表 `schemes`，价目页创建/改名/删除价目类别时同步登记/改名/解除引用）；价目页「问卷计价」弹窗（默认方案单选 + 例外编辑器，逐行回显该问卷对象档位价）；问卷页「适用价目」列显示方案名 + 默认/专属标记，行内「计价」可设专属或恢复默认。

浏览器实测（李航 · 希刻劳）：建「问卷调研」（医生/患者/商业公司三档）与「问卷调研-加急」两方案 → 默认=问卷调研、例外 QX-2026-0002→加急 → 问卷页 Q1/Q3 显示「问卷调研·默认」、Q2 显示「加急·专属」；Q3 行内设专属再恢复默认，双向写与回落全部正确；跨页面导航后状态保持（localStorage）。tsc 通过、vitest 33/33。

**入口重构（用户评审后，替代「问卷计价」全局弹窗）**：初版做了一个包含全部方案默认选择 + 全部例外清单的「上帝弹窗」，且入口复制到目录每一行——被指出违背就地编辑原则（组级/全局配置混入行级上下文）。现行形态：

- **方案上下文**：价目类别维护页内嵌「问卷计价」面板，只管当前方案——设为默认/取消默认；专属问卷 chips 就地增删（移除即回落默认；picker 中标注问卷现属，选择即改绑）。存储层配套粒度写 API（setDefaultScheme / setException / exceptionsOf），废弃整表保存。
- **问卷上下文**：问卷页行内「计价」弹窗（跟随默认/指定专属），本就按份限定，保持不变。
- 目录行不再放计价入口；弹窗与行内按钮均已删除。

仍未落地（待任务侧接入）：任务下发时按方案解析单价并快照锁定（BatchCreateTaskPage 目前排除问卷调研类）；按品种区分例外方案（如需，例外键需升为 问卷×品种）。

**模拟数据预置（免手工搭建）**：价目页种子含「问卷调研」（医生 1000/800、患者 600/500、商业公司 900/700）与「问卷调研-加急」两个预置方案（id 固定 surveyStd/surveyUrgent，随 vendor scale 缩放，无发包标准价）；问卷存储 v3 预登记这两个方案并预置 默认=surveyStd、例外=QX-2026-0002→加急。刷新即用，两侧标签与弹窗预填开箱生效。

## 落地记录（第三批：绑定场景已接入原型）【已被第四批替代】

**「价目侧绑定」端到端可演示**，两个页面通过共享存储联动：

## 落地记录（第五批：按品种归属，2026-11-10）【替代第四批的默认+例外机制】

方向变更：价目表只维护**方案与价格**；**问卷配置**维护各品种的计价归属。一份问卷共用一套题目，每个适用品种独立选择计价方案；任务按品种取价，创建时锁定。

- **数据模型 v4**（`questionnaireStore.ts`，键 `baiyee-questionnaire-store-v4`）：`Questionnaire.pricing: Record<品种, serviceId | null>`；删除 `PricingLink/defaults/exceptions` 及 `setDefaultScheme/setException/exceptionsOf/resolveSchemeForCode/defaultSchemeName`。null = 待补齐（迁移无法确定归属，或方案被删）。读取时 miss v4 键则回读 v3 键一次性迁移：适用品种展开为显式清单（全品种 → 当前全部品种），归属 = 例外 > 默认；缺价状态不落库、渲染时实时计算（价格是内存态，落库标记会失效）。
- **共享价目 store**（新 `priceTableStore.ts`）：价格矩阵从 `PriceTableConfig` 组件内 useState 提升为模块级 store（rev 自增快照修复联动失效隐患）；问卷/任务侧查询 API：`allProductNames()`、`surveyPriceOf(品种, 方案, 填写对象) → {pub, priv}`（草稿优先、业务日期选 base/split）。问卷种子价按品种下标 ×0.9 差异化（第 2 品种），演示「同名方案分品种不同价」。
- **问卷配置页**：创建弹窗按交互原型重做——品种可搜索下拉多选（全选作用于全部品种、不受搜索词影响、勾选即时同步计价行、取消勾选丢弃该品种方案）、按品种计价表（方案下拉 + 公私价只读回显 + ✓已配置/价格缺失/待选择三态）、切换填写对象整表重取价、惰性校验（名称→≥1品种→逐品种方案→逐品种公私价齐全→题目，错误汇总阻止创建）。行内「计价」→「计价归属」维护弹窗（可增删品种、保留品种方案不重置、允许留待补齐）。CSV 题目导入从原型移植（BOM 模板/引号转义/CRLF/行号报错）。
- **权限口径变更**：方案选择归 `questionnaire-config:create/edit`（创建时/维护时），不再要求 `price-config:edit`——计价归属是问卷侧内容，不应捆绑价目编辑权（按品种归属新方向修正外部评审旧结论）。
- **价目表页**：`SurveySchemePanel` 全部写入口（设/取消默认、专属问卷增删、绑定专属）移除，改为只读反查「关联问卷（按品种）」；价目类别改名接线 `renameScheme`；删类别经 `unlinkService` 把指向它的归属置 null（待补齐）。
- **任务侧全量接线**：批量创建页移除问卷类别硬排除——「问卷调研与分析服务」作为虚拟分组：勾选后按品种选问卷（启用 + 适用范围覆盖），单价 = 该问卷计价方案「填写对象」档位对公价；类别预算在参与品种间等比派生（`deriveSurveyItems`，不走统一业务比例），数量 = floor(金额/品种单价)；提交时 `buildTaskFromInput` 组装 `Task.questionnaireSnapshots`（问卷×品种 → 最新题目版本 + 公私单价深拷贝锁定），对公口径结算。品种桥接：mockData 增 希刻劳/泰诺林（百益、PB-STD-2026）+ 智联/东方恒业授权；双黄连/格华止留问卷/价目宇宙不进发包。任务详情新增「问卷计价快照」面板与明细行问卷标记。
- **第四批 v2 作废部分**：默认+例外机制、价目页默认/专属入口、问卷页跟随默认弹窗、「新建问卷不强制选价目」（改为创建时必须配置完整）。
- 验证：`tsc --noEmit` 通过；vitest 60/60（含 v3→v4 迁移、绑定/unlink/rename、surveyPriceOf、CSV、deriveSurveyItems、快照深拷贝）；`vite build` 通过。
